First test version of the Google Drive binding for **openHAB 5.0 or later** (does not start on 4.x).

## Included
- `account` bridge: Google login with a device code (google.com/device), automatic token refresh
- Storage quota channels `quotaUsed` and `quotaTotal`
- `logout` rule action
- `backup` thing with all settings and channels – **the upload itself is not implemented yet** (milestone M3)
- English and German texts

## Installation
1. Download `org.openhab.binding.googledrive-0.1.0.jar` below.
1. Copy it into the `addons` folder of openHAB (Docker: `/openhab/addons`).
1. Set up the Google Cloud project as described in the README ("Google Cloud Setup"), then add the `account` bridge.
