Backup upload. Requires **openHAB 5.0 or later**.

## New
- `backup` thing uploads new backups from `userdata/backup` automatically, as soon as the archive is completely written
- Resumable upload in 8 MB chunks; continues after network errors, failed uploads are retried twice (5 minutes apart)
- Checksum check: the uploaded file is verified, files already in Google Drive are not uploaded twice
- Old backups beyond "Backups to Keep" are moved to the trash or deleted
- Target folder is created by the binding; paths like `openHAB/Backups` create nested folders; the folder may be renamed or moved in Drive
- Channels: status, progress, last upload, last file, last size, backups in Drive, last error, upload events
- Rule actions: `uploadLatest()`, `uploadFile(fileName)`, `cleanup()`
