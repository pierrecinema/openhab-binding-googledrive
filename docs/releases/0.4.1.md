Beta version of the Google Drive Binding. Requires **openHAB 5.0 or later**.

## Fixed
- Dashboard widget: the **Upload now** button did nothing. It now starts the upload after the confirmation.

The binding itself is unchanged. If you use the widget, replace it with the new `googledrive_backup_card.yaml` under **Developer Tools → Widgets**. You do not have to change the JAR.

## Feedback
Please report problems as [GitHub issue](https://github.com/pierrecinema/openhab-binding-googledrive/issues) or in the [openHAB community thread](https://community.openhab.org/t/google-drive-binding-automatic-openhab-backups-to-google-drive/170779).
