Safer backup detection. Requires **openHAB 5.0 or later**. Thanks to the forum suggestion!

## New: completed-archive check
- An unchanged file size for `stableSeconds` can also mean that the backup script stalled, not that it finished.
- Before every upload (automatic and manual) the binding now opens the ZIP file and reads every entry with its CRC. A half-written or damaged archive is **not uploaded**; the binding keeps waiting.
- If a backup is still incomplete after 10 minutes, a warning is written to the log and to the *Last Error* channel.
- Because incomplete archives are never uploaded, they can no longer push a good older backup out of Google Drive during cleanup.

## Update from 0.3.0
Delete `org.openhab.binding.googledrive-0.3.0.jar` from the `addons` folder and copy `org.openhab.binding.googledrive-0.4.0.jar`. Things, items and the Google login are kept.
